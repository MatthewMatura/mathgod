# Count With Me

A playful maths site for young kids. Pick an activity from the home screen. Every activity can use puppies, circles, beach balls, snowflakes, stars, apples, butterflies, kittens, fish or hearts, and can talk out loud.

| Activity | What happens |
| --- | --- |
| 🔢 Count | Type any number up to 10,000 and the board fills up. Group into 2s–100s, mix up, or set them moving. |
| ➕ Equations | Build `3 + 4`, `7 − 3`, `3 × 4` or `12 ÷ 3`, press **=**, and watch it happen: piles join, items walk away, groups become a grid (with a flip button), or items get dealt into groups. |
| 🤔 Guess how many | Items wander around, then hide. Guess, then they line up in tens to check. |
| ⚡ Quick look | Items flash for a second or two. How many did you see? |
| ❓ Missing number | `5 + ? = 8`: tap the empty spots or type the answer. |
| 🔟 Make 10 | How many more to fill the ten-frame (or 20)? |
| 👯 Odd or even | Pair everyone up and see if one is left over. |
| 🦘 Skip counting | Tap each group to count by 2s, 3s, 4s, 5s or 10s. |
| ⚖️ Which is more? | Two piles. Pick the bigger one, then they line up to compare. |
| 📖 Story time | Little word problems that act themselves out. |

It is a single static page (`index.html`) with no build step, hosted with GitHub Pages.
